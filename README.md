# Pentimento Text Core Bootstrap

این پکیج برای ساخت نسخهٔ متنی Pentimento از صفر تهیه شده است.

## هدف فعلی
فقط Text Core را بساز:
Player Text → Context Builder → AI Director → Validator → Game Engine → Memory/Event → Text Response

## فعلاً خارج از دامنه
- Telegram
- React/UI
- CSS
- responsive/mobile
- reward UI
- production deployment
- vector DB / graph memory
- multi-agent frameworks

## ترتیب کار
1. `PENTIMENTO.md` را به‌عنوان canon بخوان.
2. `AGENT_RULES.md` را به‌عنوان قواعد غیرقابل‌مذاکره بخوان.
3. `TEXT_CORE_SPEC.md` را دقیقاً پیاده‌سازی کن.
4. `CONTRACTS.ts` قراردادهای هسته است؛ می‌توانی مسیر فایل‌ها را عوض کنی ولی مرزهای معنایی را نه.
5. `ACCEPTANCE_TESTS.md` معیار قبولی است.
6. متن `START_PROMPT.txt` را به Agent بده.

هدف اولین milestone فقط NODE 01 است.
اگر NODE 01 واقعاً حس Dungeon Master ندهد، هیچ Node دیگری نباید پیاده‌سازی شود.
